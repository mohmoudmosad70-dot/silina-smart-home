# Silina Smart Home

## التشغيل
1. ثبّت Node.js (الإصدار 18 أو أحدث)
2. افتح الترمينال داخل المجلد ثم نفّذ:
   npm install
   npm start
3. افتح المتصفح على http://localhost:3000

بيانات الدخول الافتراضية: admin / 123456 (غيّرها بعد أول دخول)

## ملاحظات
- مجسم الشقة موجود في: public/models/apartment2/apartment2.fbx
- لتغيير مفتاح JWT: JWT_SECRET=مفتاح_قوي npm start
- مجسم الشخصية: public/models/boy/boy.fbx
